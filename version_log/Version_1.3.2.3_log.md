# Version 1.3.2.3 Log

Date: 2026-03-29
Target: Minecraft 1.21.7 / Fabric Loader 0.18.4
Supported Languages: Japanese, English, Simplified Chinese, Literary Chinese, Literary Chinese (Simplified Script)

## Japanese

### 概要

- 分解と残響消費に、3回クリック確認を追加しました。

### 更新内容

- 武器分解を3回クリック確認式に変更
- 残響を素材に使う装備強化を3回クリック確認式に変更
- 対象や素材が変わった場合、確認段階を即リセットするよう修正

## English

### Summary

- Added a 3-click confirmation flow to dismantling and Echo-consuming upgrades.

### Changes

- Weapon dismantling now requires 3 confirmation clicks
- Equipment upgrades that consume another Echo now require 3 confirmation clicks
- Confirmation progress now resets immediately when the target or material changes

## 简体中文

### 概要

- 为分解与消耗残响的强化新增了三次点击确认。

### 更新内容

- 武器分解改为三次点击确认后才执行
- 消耗其他残响的装备升级改为三次点击确认后才执行
- 当目标或素材发生变化时，确认进度会立刻重置

## 文言

### 更新

- 解兵今須三擊而後行
- 吞他殘響以昇裝者，今須三擊而後行
- 若所對之物或其材有變，則所驗之數即歸初
