# Version 1.3.2.4 Log

Date: 2026-03-29
Target: Minecraft 1.21.7 / Fabric Loader 0.18.4
Supported Languages: Japanese, English, Simplified Chinese, Literary Chinese, Literary Chinese (Simplified Script)

## Japanese

### 概要

- 武器入手をガチャ中心へ寄せ、コード進行の新規入手手段として周辺生成型の宝箱を追加しました。

### 更新内容

- 武器の「欠片から合成」機能を撤廃
- `rondo_melody` と `masquerade_invitation` の本体直ドロップを停止し、武器本体はガチャ入手前提へ変更
- プレイヤー周囲に動的生成される宝箱を追加
- 宝箱報酬を `★3 = 400 CSC + 100 CP`、`★4 = 1000 CSC + 125 CP`、`★5 = 1500 CSC + 150 CP` に設定
- 宝箱は寿命なし・所有者ロックなしに変更
- 宝箱の同時生成上限を各プレイヤー `5` 個に拡張

## English

### Summary

- Shifted weapon acquisition toward resonance-only pulls and added dynamic treasure chests as a new Chord Progression source.

### Changes

- Removed the old weapon crafting flow from fragments
- Stopped direct field drops of `rondo_melody` and `masquerade_invitation`, so complete weapon stacks now come from resonance
- Added dynamic treasure chests that spawn around players
- Set treasure-chest rewards to `3-star = 400 CSC + 100 CP`, `4-star = 1000 CSC + 125 CP`, and `5-star = 1500 CSC + 150 CP`
- Removed treasure-chest lifetime limits and owner locks
- Increased the active treasure-chest cap to `5` per player

## 简体中文

### 概要

- 将武器获取进一步收束到奏鸣，并新增了玩家周边动态宝箱作为和弦进行的获取方式。

### 更新内容

- 移除了武器“由碎片合成”的功能
- 停止 `rondo_melody` 与 `masquerade_invitation` 的完整武器野外直掉，完整武器改为以奏鸣获取为主
- 新增会在玩家周围动态生成的宝箱
- 宝箱奖励设为 `3星 = 400 CSC + 100 CP`、`4星 = 1000 CSC + 125 CP`、`5星 = 1500 CSC + 150 CP`
- 宝箱改为无寿命、无所有者锁
- 每名玩家的同时存在宝箱上限提升至 `5` 个
