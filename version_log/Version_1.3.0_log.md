# Version 1.3.0 Log

Date: 2026-03-28
Target: Minecraft 1.21.7 / Fabric Loader 0.18.4
Supported Languages: Japanese, English, Simplified Chinese, Literary Chinese, Literary Chinese (Simplified Script)

## Japanese

### 概要

- このバージョンでは、戦闘成長ループを一段進め、武器、CSC経済、ショップ、秘境、実テクスチャ差し替えをまとめて正式化しました。

### 更新内容

- JSONベースの武器システムを追加
- 新武器「円舞曲のメロディ」「マスカレードへの誘い」を追加
- 武器の基礎レベルとスキルレベルを分離し、CSCで成長可能に変更
- 武器ごとの右クリックスキルと個別クールダウン表示を追加
- `CreSora Credits (CSC)` を恒久通貨として導入
- `/cresora_credits` と `/cresora_shop` を追加
- 聖遺物強化コストをXPからCSCへ変更
- `残響のカナタ・α式` と `残響のカナタ・β式` を追加
- 秘境システム `/cresora_domain` を追加
- 雛形・円舞曲・マスカレード用の周回先を実装
- 敵ドロップ対象を広げ、CSC / 冒険ランク経験値 / 欠片報酬を拡張
- セット効果ツールチップをJSON内容から描画するよう変更
- 日本語名で提供されたPNGを正式アセットへ取り込み、仮テクスチャを置換

## English

### Summary

- This version pushes the combat-growth loop forward and formalizes weapons, the CSC economy, the shop, domains, and custom production textures into one release.

### Changes

- Added a JSON-driven weapon system
- Added the new weapons `Melody of the Rondo` and `Invitation to the Masquerade`
- Split weapon growth into base level and skill level, both upgraded through CSC
- Added per-weapon right-click skills and independent cooldown displays
- Added `CreSora Credits (CSC)` as the persistent currency layer
- Added `/cresora_credits` and `/cresora_shop`
- Changed artifact upgrade costs from XP to CSC
- Added `Zankyo no Kanata Alpha` and `Zankyo no Kanata Beta`
- Added the `/cresora_domain` domain system
- Implemented focused farming routes for Hinagata, Rondo, and Masquerade content
- Expanded hostile rewards across CSC, Adventure Rank XP, and weapon fragments
- Changed set-bonus tooltips to render from JSON-backed content data
- Imported the provided Japanese-named PNG files as final in-game textures, replacing placeholder art
