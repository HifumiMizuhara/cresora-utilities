# Version 1.3.2.2 Log

Date: 2026-03-29
Target: Minecraft 1.21.7 / Fabric Loader 0.18.4
Supported Languages: Japanese, English, Simplified Chinese, Literary Chinese, Literary Chinese (Simplified Script)

## Japanese

### 概要

- 武器の分解機能と、`レクエイム` / `湖畔` の欠片周回秘境を追加しました。

### 更新内容

- 武器強化画面に `分解` ボタンを追加
- 武器を同系統の欠片へ戻せるように変更
- 分解返却量を、レアリティと基礎Lv投資量に応じて変動する仕様へ設定
- `レクエイム霊廟` を追加し、`requiem_toward_dawn_fragment` を集中周回可能に変更
- `湖畔の聖域` を追加し、`lakeside_stride_fragment` を集中周回可能に変更
- 上記 UI / 秘境名 / メッセージを全対応言語へ追加

## English

### Summary

- Added weapon dismantling plus focused fragment domains for `Requiem Toward Dawn` and `Stride by the Lakeside`.

### Changes

- Added a `Break` button to the weapon upgrade screen
- Weapons can now be dismantled back into their own fragments
- Set dismantle refunds to scale with rarity and invested base levels
- Added `Requiem Reliquary` for focused `requiem_toward_dawn_fragment` farming
- Added `Lakeside Sanctum` for focused `lakeside_stride_fragment` farming
- Added the related UI text, domain names, and messages in every supported language

## 简体中文

### 概要

- 新增武器分解功能，以及 `安魂` / `湖畔` 两条专用碎片周回秘境。

### 更新内容

- 在武器升级界面新增 `分解` 按钮
- 武器现在可以分解回对应的自身碎片
- 分解返还数量改为随稀有度与基础等级投入而变化
- 新增 `安魂藏所`，可集中刷取 `requiem_toward_dawn_fragment`
- 新增 `湖畔圣所`，可集中刷取 `lakeside_stride_fragment`
- 以上界面文本、秘境名称与消息已补齐到全部支持语言
