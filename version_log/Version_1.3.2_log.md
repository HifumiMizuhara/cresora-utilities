# Version 1.3.2 Log

Date: 2026-03-29
Target: Minecraft 1.21.7 / Fabric Loader 0.18.4
Supported Languages: Japanese, English, Simplified Chinese, Literary Chinese, Literary Chinese (Simplified Script)

## Japanese

### 概要

- `音律エコー` を導入しました。`v1.3.2` では全モブの被ダメージが `3%` 減少します。

### 更新内容

- 新しい定期モブ補正システム `音律エコー` を追加
- `v1.3.2` のアクティブ補正として、全モブに `受けるダメージ -3%` を適用
- 将来のバージョンごとのモブ補正を、専用 JSON から切り替えられる構成へ整理

## English

### Summary

- Added `Music Echo`, a periodic mob-tuning layer. In `v1.3.2`, all mobs take `3%` less damage.

### Changes

- Added a new recurring mob-buff system named `Music Echo`
- Applied `damage taken -3%` to all mobs as the active `v1.3.2` tuning rule
- Moved version-based mob tuning onto a dedicated JSON resource so future balance rotations no longer need hardcoded edits
